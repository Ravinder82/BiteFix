# Phase 3 — Design System: Mascot · Colors · Components

## 3.1 Mascot Creation Workflow

**Goal:** A character that embodies the app's personality — used across splash, onboarding, empty states, success screens, and error states.

### Tools
- **Figma** → `figma.com` (free tier sufficient)
- **Stitch** → `stitchdesign.ai` (AI-assisted component generation)
- **LottieFiles** → `lottiefiles.com/editor` (animate mascot)
- **SVGator** → `svgator.com` (SVG animation)

### Mascot Design Brief Template

```
Character Name: ___________
Personality: [Friendly / Professional / Playful / Bold]
Core emotion: [Trust / Excitement / Calm / Energy]
Primary feature: [Eyes / Shape / Accessory]
Color palette: derives from brand colors
Required poses:
  - Idle/wave (onboarding)
  - Happy/celebrate (success)
  - Thinking (loading)
  - Sad/error (error state)
  - Sleep (empty state)
Export: SVG (static) + Lottie JSON (animated)
```

## 3.3 Base Components Build Order

Build in this sequence — each depends on the previous:

1. `Typography` (Text, Heading, Label)
2. `Button` (primary, secondary, ghost, destructive sizes: sm/md/lg)
3. `Input` (text, password, search, textarea)
4. `Card` (surface container with optional press)
5. `Badge` (status indicators)
6. `Avatar` (image with fallback initials)
7. `Divider`
8. `Skeleton` (loading placeholder)
9. `Modal` (bottom sheet and center modal)
10. `Toast` / `Snackbar`

## 5.2 Custom Animated Tab Bar

```tsx
// src/components/layout/AnimatedTabBar.tsx
import Animated, {
  useSharedValue, useAnimatedStyle, withSpring, withTiming,
} from 'react-native-reanimated';
import * as Haptics from 'expo-haptics';

function TabBarButton({ icon: Icon, label, isFocused, onPress }) {
  const scale = useSharedValue(1);
  const opacity = useSharedValue(isFocused ? 1 : 0.5);

  useEffect(() => {
    scale.value = withSpring(isFocused ? 1.2 : 1, { damping: 10 });
    opacity.value = withTiming(isFocused ? 1 : 0.5, { duration: 200 });
  }, [isFocused]);

  const animStyle = useAnimatedStyle(() => ({
    transform: [{ scale: scale.value }],
    opacity: opacity.value,
  }));

  const handlePress = () => {
    Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    onPress();
  };

  return (
    <TouchableOpacity onPress={handlePress} className="flex-1 items-center py-2">
      <Animated.View style={animStyle}>
        <Icon size={24} color={isFocused ? colors.primary : colors.textMuted} />
      </Animated.View>
      <Text className={`text-xs mt-1 ${isFocused ? 'text-primary' : 'text-muted'}`}>
        {label}
      </Text>
    </TouchableOpacity>
  );
}
```

### Gesture-Driven Dismiss
```tsx
import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import { useSharedValue, useAnimatedStyle, withSpring, runOnJS } from 'react-native-reanimated';

const translateY = useSharedValue(0);
const pan = Gesture.Pan()
  .onUpdate(e => { translateY.value = Math.max(0, e.translationY); })
  .onEnd(e => {
    if (e.translationY > 100) runOnJS(dismiss)();
    else translateY.value = withSpring(0);
  });
```

# Phase 8 — Onboarding Screens

## 8.1 Flow Architecture

```
AsyncStorage check (onboarding_complete) → If false: show onboarding
  Screen 1: Welcome / Mascot Introduction
  Screen 2: Key Feature 1 (animated demonstration)
  Screen 3: Key Feature 2
  Screen 4: Permissions (Notifications — explain value first)
  Screen 5: Auth prompt (Sign Up / Log In / Skip)
```

## 8.2 Onboarding State Management

```ts
// src/hooks/useOnboarding.ts
import AsyncStorage from '@react-native-async-storage/async-storage';

const ONBOARDING_KEY = '@onboarding_complete_v1';

export function useOnboarding() {
  const [isComplete, setIsComplete] = useState<boolean | null>(null);

  useEffect(() => {
    AsyncStorage.getItem(ONBOARDING_KEY).then(val => {
      setIsComplete(val === 'true');
    });
  }, []);

  const completeOnboarding = async () => {
    await AsyncStorage.setItem(ONBOARDING_KEY, 'true');
    setIsComplete(true);
  };

  return { isComplete, completeOnboarding };
}
```

# Phase 9 — Production Build

## 9.1 Pre-Build Checklist

```bash
# Validate legal URLs
node scripts/validate-legal-urls.js

# Check TypeScript
npx tsc --noEmit

# Run linter
npx eslint src/ --max-warnings 0

# Check bundle size
npx expo export --platform ios
```

## 9.2 Build Commands

```bash
# iOS Production
eas build --profile production --platform ios --auto-submit

# Android Production
eas build --profile production --platform android --auto-submit

# Manual submit (if auto-submit skipped)
eas submit --profile production --platform ios
eas submit --profile production --platform android
```

## 9.3 OTA Updates (Post-Approval)

For JS-only changes (no native changes), use OTA — no App Store review needed:

```bash
eas update --branch production --message "Fix: [description]"
```

Configure in `app.json`:
```json
"updates": {
  "enabled": true,
  "checkAutomatically": "ON_LOAD",
  "fallbackToCacheTimeout": 0
}
```

## 9.4 Monitoring Setup

- **Crashlytics**: `@react-native-firebase/crashlytics` — crash alerts
- **Analytics**: Firebase Analytics — user flows, drop-offs
- **Performance**: Firebase Performance — screen load times
- **Reviews**: Monitor App Store Connect → Customer Reviews daily for first 2 weeks

## 9.5 App Store Review Timeline

| Stage | Typical Duration |
|---|---|
| Initial review (new app) | 1–3 days |
| Update review | 24–48 hours |
| Expedited review (urgent bug) | 24 hours (request in ASC) |
| After rejection + fix | 1–2 days |

**Rejection → Fix → Resubmit:** Always reply to the rejection in the Resolution Center with a clear explanation of what you changed.
